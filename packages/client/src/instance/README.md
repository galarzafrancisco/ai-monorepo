# Instance Client Layer

This directory contains handwritten, instance-based APIs for `@taico/client`.

Why it exists:
- The generated files under `packages/client/src/client/` are built around a global `OpenAPI` singleton.
- That global shape is not safe for multiple concurrent auth contexts such as one worker token plus many agent tokens.
- The generated request core in `src/client/core/request.ts` already accepts a per-client config object, so this handwritten layer uses that directly.

Important:
- `packages/client/src/client/` is regenerated by `npm run generate:client`.
- Do not put handwritten code inside `src/client/`.
- Put handwritten instance-client code under `src/instance/` and export it from `src/index.ts`.

## How To Add A New Method

When a new backend endpoint is added and codegen produces new DTO/model types:

1. Find the generated static service method in `src/client/services/*.ts`.
   Use it as the source of truth for:
   - HTTP method
   - URL path
   - path params
   - query params
   - request body type
   - expected response type
   - explicit error mappings

2. Add the method to the relevant handwritten API class in this directory.
   Current classes:
   - `AgentsApi`
   - `TasksApi`

3. Reuse generated request/DTO types instead of inventing new local transport types.
   Import from:
   - `../client/core/request.js`
   - `../client/models/...`
   - `../client/core/CancelablePromise.js` only if needed

   If the generated client has not been regenerated for a new endpoint yet and the DTO types do not exist under `src/client/models/`, define a small local type next to the handwritten method as a temporary measure. Replace that local type with generated imports the next time the package is regenerated.

4. Mirror the generated service method closely.
   Keep the request options object aligned with the generated version so drift stays minimal.

5. Expose the new method through `createTaicoClient()` if it belongs on the public instance client.

6. Validate:
   - `npm -w packages/client run typecheck`
   - any consumer typecheck that uses the new method

## Pattern

Use this pattern inside an API class:

```ts
async someMethod(input: SomeDto): Promise<SomeResponseDto> {
  return request<SomeResponseDto>(this.config, {
    method: 'POST',
    url: '/api/v1/example',
    body: input,
    mediaType: 'application/json',
    errors: {
      400: 'Bad Request',
    },
  });
}
```

Do not:
- mutate the generated global `OpenAPI`
- import or edit files under `src/client/` manually
- add worker-specific behavior here

This layer should stay a thin per-instance transport binding over generated contracts.
