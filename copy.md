# Anchor tagline
Use when you need a single memorable line.

> Threads connect humans and agents so work moves with shared context.

# Short product description
Best for hero copy, README intros, or a quick overview.

> A workspace where people and AI agents collaborate in threads, turn intent into tasks, and execute with shared memory.

Option B (punchier):

> A workspace for humans and AI agents to delegate, coordinate, and finish work without wrestling integrations.

# Mental model (five-part explainer)
Good for onboarding docs or product explainers.

> Tasks are promises.
> Threads are the collaboration space.
> Agents carry out the work.
> Context is durable memory.
> Tools widen what the team can do.

# What it replaces
Use this when positioning against familiar tools without picking a fight.

> This is not Jira, Slack, or Confluence.
> It is how work looks when some teammates are AI.

Option B:

> We did not replace Jira, Slack, and Confluence.
> We removed the friction between them.

# Why it exists
Problem framing for decks, websites, or investor conversations.

> Most software assumed humans coordinating with humans.
> AI changes that premise.

Option B (blunter):

> We have been duct-taping AI into human tools.
> This is software built for mixed human AI teams from day one.

# Threads explain the system
Use when defining the core abstraction.

> A thread is a focused stream of intent.
> Humans and agents work together inside threads.
> Tasks, context, and decisions are artifacts of the thread.

# Orchestration mindset
Use to explain the state-driven model.

> You do not manage agents.
> You change state and the system responds.

Option B:

> Work flows through the system via state changes, not commands.

# Why it is hard to demo
Set expectations and emphasize compounding value.

> This is not a flashy demo product.
> It gets better on day two.

Option B:

> The value is not what it does in five minutes.
> It is what you stop carrying after a week.

# Enterprise mic-drop
Use for sales decks or executive summaries.

> This is where work happens when AI is part of the team.

# Poetic flow
Use sparingly in talks or manifesto-style pages.

> Conversations become threads.
> Threads crystallize into tasks.
> Agents execute.
> Context accumulates.
> Work moves forward.
